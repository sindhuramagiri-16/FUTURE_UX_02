# FUTURE_UX_02

## Project
Daily Rituals – Cafe Mobile App UI

## Objective
Designed a modern mobile app UI for Daily Rituals, focused on creating a smooth café discovery and ordering experience with an aesthetically pleasing and user-friendly interface.

## Features
- Onboarding flow
- Login / Signup screen
- Home screen with featured cafés
- Daily specials and recommendations
- Menu browsing
- Food & beverage categories
- Order customization
- Cart and checkout flow
- Order confirmation screen
- Light mode / Dark mode / Default mode support

## Tools Used
- Figma
- Google Fonts
- Icons
- Unsplash (for café images)

## Design Style
- Premium café-inspired UI
- Warm coffee color palette
- Modern card-based layout
- Smooth user flow
- Clean typography with soft shadows

## Color Palette
- Coffee Brown: #6F4E37
- Cream: #F8F4EC
- Dark Coffee: #3E2723
- Accent Beige: #D7CCC8
- White: #FFFFFF

## Fonts
- Headings: Poppins Bold
- Body: Inter Regular

## Design Rationale
The Daily Rituals app was designed with a mobile-first approach focused on providing a cozy and premium café experience. The interface uses warm coffee-inspired colors and clean layouts to create familiarity and comfort. The navigation flow reduces user effort by enabling quick menu browsing, easy ordering, and a streamlined checkout experience. Multiple display modes improve accessibility and personalization for different user preferences.
