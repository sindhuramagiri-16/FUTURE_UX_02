# 12. HOW TO MAKE IT LOOK PROFESSIONAL

## DO:

✅ Use lots of white space
✅ Use rounded corners (20–28px)
✅ Keep shadows soft
✅ Use only 2–3 colors
✅ Use same button style everywhere
✅ Maintain spacing consistency
✅ Use large clean images

## DON'T:

❌ Overuse gradients
❌ Add too many colors
❌ Use crowded layouts
❌ Use random fonts

# ✨ Design Rationale

## Project:

Brew Haven Café — Mobile Appointment Booking App

## Objective

The goal of this project was to design a smooth and minimal mobile booking experience for café customers looking for comfortable seating and hassle-free reservations.

## Target Users

* Students
* Couples
* Remote workers
* Friends groups
* Coffee lovers

## UX Decisions

* Soft color palette creates a relaxing feeling
* Large cards improve readability
* Minimal navigation reduces booking friction
* Rounded UI improves friendliness
* Time-slot chips make booking faster

## Problem Solved

The app simplifies traditional café reservations by replacing phone calls and manual bookings with an easy mobile-first experience.
